# Classification_Assignment
ML Assignment 03 - Classification Algorithms Model Building
# Overview
This assignment implements and compares five classification algorithms using the Scikit-learn breast cancer dataset.
# Algorithms Used
Logistic Regression.
Decision Tree Classifier.
Random Forest Classifier.
Support Vector Machine (SVM).
k-Nearest Neighbors (k-NN).
# Preprocessing
The dataset was checked for missing values, split into training and testing sets and scaled using StandardScaler.
# Evaluation
The models were evaluated and compared using accuracy. Classification reports were also generated to examine precision, recall and F1-score.
